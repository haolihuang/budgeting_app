# Household Annual Budget Planner

Open [`index.html`](/Users/haolihuang/Desktop/Codex%20test/index.html) in a browser to use the tool.

It models:

- paycheck amount, timing, and interval
- fixed monthly household costs
- recurring spending with different frequencies
- discretionary monthly budgets
- month-by-month ending balance across a full year

No build step or package install is required.
